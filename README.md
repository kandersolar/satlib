# satlib

`satlib` is a package for simulating simulating control algorithms
for single-axis solar trackers like the ones found in large solar
photovoltaic power plants.

Following [pvlib's](https://github.com/pvlib/pvlib-python) example, it provides
a toolbox of functions that the user combines as they like to form simulation
workflows.

```
pip install git+https://github.com/kandersolar/satlib.git
```
